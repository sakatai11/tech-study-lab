# 0020: 性能試験は Web Worker を経由した静的な枠の配信を測る

- 状態: Accepted
- 日付: 2026-11-07
- 関連: Issue #291、Issue #288（ADR-0017 が引き継ぐ ADR-0016 の測定条件と、ADR-0019 の境界にある測定条件を補正する）

## 背景

ADR-0019 の4画面では、Web Worker がビルド済みの HTML / RSC を静的アセットから取得する。性能試験が SSR 用の条件を引き継ぐと、Vinext の静的成果物を正常に配信した応答を拒否してしまう。一方、Cloudflare のエッジキャッシュが返した応答を含めると、測りたい配信処理の CPU 時間を計測できない。

## 決定

1. バージョン確認と本計測では `x-vinext-cache: HIT` を要求し、静的な枠の配信を確認する。リクエストはローカルキャッシュを使わない設定で送り、応答の `Cache-Control` は測定結果に記録する。Cloudflare がエッジキャッシュから本文を返したと示す `CF-Cache-Status` は拒否する。
2. CI では、確認用と本計測用の全リクエストを、それぞれ期待する Web Worker バージョンの正常な invocation log と Ray ID で照合する。応答ヘッダーによる判定と実行ログの照合の両方を通過したときだけ成功とする。
3. 静的配信の測定には新しい条件識別子を使う。旧条件の結果は、自動比較の基準と本番昇格の証跡から外す。

## 境界

- 対象は検証環境の `/home`・`/review`・`/domains`・`/analytics` の HTML / RSC。手動のブラウザ測定にも同じ応答条件を適用する。
- ユーザー固有データの取得・キャッシュは ADR-0019 に従う。配備順序、測定件数、バージョン照合と本番昇格の条件は ADR-0017 と ADR-0018 に従う。

## 検証

- [performance.test.mjs](../../scripts/performance.test.mjs): 静的な枠の応答条件、エッジキャッシュの拒否、バージョン確認と本計測を検証する。
- [deployment.test.mjs](../../scripts/deployment.test.mjs): 旧測定条件の証跡で本番昇格できないことを検証する。
