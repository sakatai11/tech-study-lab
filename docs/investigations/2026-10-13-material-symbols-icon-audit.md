# Material Symbols アイコン利用の棚卸し

実施日：2026-10-13。Issue #233。#230 / PR #231 で `/learn` に導入した Material Symbols Rounded をアプリ全体へ広げるため、既存の記号・絵文字とアイコンが足りない箇所を棚卸しし、P1・P2 を実装した。アイコンの方針（サイズ・配置・意味の対応・例外）は design.md の 旧 7.2 節・旧 8.7 節 が一次ソースであり、本文書は判断の経緯と未確認・未対応の事項だけを残す。

## 確認範囲

基準コードは `origin/develop`（`49ef998`）。ローカル dev（api :8787 / web :3000、ローカル D1 に migration と content を適用）を Playwright で操作した。PC（1440×900）と SP（390×844）、ダーク・ライトのすべての組み合わせで、共通シェル・`/`・`/home`・`/learn/**`・`/quiz/[lesson]`・`/review`・`/domains`・`/analytics` を確認した。スクリーンショットは確認にだけ使い、リポジトリには残していない。

画面で確認できず、コードでのみ確認した状態：

- 各ルートの `error.tsx` と `DashboardDueCard` の取得失敗時表示。ローカル dev では API プロセスを止めても、Web が Service Binding 経由で取得を続けるため、エラー境界を表示できなかった。
- 採点中の `>_ grading...`（応答が速い一時状態）。
- 問題0件の演習・「次のレッスンへ」・「次の復習を取得」。現行 content はレッスン1本・3問で到達できない。
- ナビの無効項目と `/learn` のレッスン0件トピック。現行データでは到達できない。
- `loading.tsx` は未実装、404 は独自 UI なし。

## 判断の要点

| 対象 | 判断 | 理由 |
| --- | --- | --- |
| ナビ・テーマ切替の記号（`▦ ▤ ✎ ↻ ▥ ⌘ ☀ ◐`） | 差し替え（P1） | フォント依存で大きさ・字形が揃わない。`◐` は半分しか表示されず、`⌘` は Command キー、`↻` は再読み込みと誤読される |
| 解答後の選択肢 | アイコンと読み上げ名を追加（P1） | 正解・誤答を枠と背景の色だけで区別しており、WCAG 1.4.1 を満たさない |
| 導線の `→` / `←`、統計カードの `#`、アクティビティの `>` `▤`、ストリークの `🔥` | 差し替え（P2） | 意味を運ばない装飾、または OS・フォントで見た目が変わる |
| 学習領域カード | 領域アイコンを追加（P2） | `/learn` と同じ領域を同じ形・色で識別できるようにする |
| ロゴ `›_`、パンくず `~/devpath $`、`>_ grading...`、`PASS / FAIL`、キーキャップ、草 | 現状維持 | 旧 8.7 節 のターミナル表現そのもの。文字で意味が伝わり、色だけにも依存しない |
| 再挑戦・間違えた問題だけ復習、`error.tsx` の復旧操作 | 文字のみ | 同じ画面内の状態切替と復旧操作。SP でボタンが折り返すため、アイコンを増やさない |
| スキルツリーの ✓ / ▶ / 🔒 | 保留 | ツリーは未実装。置き換えるかはツリー実装時に決める |

ナビの「スキルツリー」には `category` を使い、`account_tree` はアーキテクチャ領域専用とした。「演習」には、ノートに鉛筆の `contract_edit` を使う。

## アクセシビリティの確認

- アイコンは常に文字ラベルと併記し、`aria-hidden` にした。例外はテーマ切替だけで、`html[data-theme]` に応じて CSS で出し分ける `sr-only` テキストを読み上げ名にしている。
- アイコンは `currentColor` を継承するため、既存の文字色トークンのコントラスト（WCAG AA）をそのまま保つ。
- 全体の `:focus-visible`（2px `--blue`）がナビ・ボタン・リンクに出ることを確認した。
- タッチターゲットは `min-h-11`（44px）を維持している。SP 下部タブは 24px アイコンと 11px ラベルで収まる。
- 導線ボタンへの 20px アイコンは `flex-wrap` の範囲で収まり、SP 幅でも崩れない。
