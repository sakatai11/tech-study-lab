# フロントエンド日本語文言の棚卸し

実施日：2026-10-13。Issue #234。フロントエンドに表示する日本語の文言を棚卸しし、改善候補・用語と表記の方針を整理し、P1・P2（C1〜C25）を同じ PR で実装した。表示文言の方針の一次ソースは [デザインシステムと画面の規約](../design-system.md) の「表示文言」（当時は design.md の旧 8.7 節）で、本書の「用語・表記の方針」は判断の理由を残す。判断の基準は、画面・導線とデザインシステム・アクセシビリティは [デザインシステムと画面の規約](../design-system.md)、エラー表示は [設計文書 5.7](../design.md#57-エラー処理)、表示名の持ち場所は [コンテンツ規約](../content-guidelines.md)、統計値の意味は [ADR-0007](../adr/0007-analytics-aggregation-boundaries.md)・[ADR-0005](../adr/0005-srs-review-rules.md) とした（当時の参照先は design.md の旧 7・8.7・9.6・11.3・4.4・4.5・7.3 節）。アイコンの方針は [Material Symbols アイコン利用の棚卸し](./2026-10-13-material-symbols-icon-audit.md)（#233）に従う。

## 確認範囲

基準コードは `develop`（`3a6e59c`、#233 マージ後）。`apps/web/src` と `packages/shared/src` から日本語文字列・`aria-label`・`sr-only` テキストを抽出し、表示条件と値の出どころをコードで確認した。そのうえでローカル dev（api :8787 / web :3000、既存のローカル D1）を内蔵ブラウザで操作し、SP（375×812・ダーク）で `/`・`/home`・`/review`（空キュー）・`/domains`・`/analytics`・`/quiz/[lesson]`（イントロ→解答→結果）を確認した。スクリーンショットは確認にだけ使い、リポジトリには残していない。

画面で確認できず、コードでのみ確認した状態：

- PC 幅（サイドバー）の表示。文言は SP と同じ定数から出るため、コードで確認した。ライトテーマも同様。
- 各ルートの `error.tsx`、`DashboardDueCard` の取得失敗表示、解答送信の失敗表示。#233 と同じ理由で、ローカル dev ではエラー境界を表示できない。
- `/review` の due あり状態（イントロ・プレビュー・結果）、「次の復習を取得」、「次のレッスンへ」、問題0件の演習、ナビの無効項目。現行データ（レッスン1本・3問、due 0件）では到達できない。
- `/learn`・`/learn/[domain]/[topic]`・教材本文は SP で未確認。静的な文言のため、コードで確認した。

## 用語・表記の方針

### 日本語・英語・カタカナの扱い

- **本文・ラベル・ボタン・単位は日本語**にする。`topic` / `lesson` / `markdown` / `content bundled` / `due` / `day streak` / `max 20` のような英語を本文や件数に混ぜない。
- **ターミナル表現は英語のまま残す**（旧 8.7 節）。ロゴ、パンくず（`~/devpath $ …`）、アイブロウ（`quiz / intro`、`SKILL TREE` 等）、`>_ grading...`、`PASS` / `FAIL`、ファイル名風ラベル（`learning-pipeline.ts`）が対象。ただし、アイブロウは画面名と一致させる（例：`/domains` の `skill tree`）。
- **技術用語は利用者に必要な場合だけ残す**。`SRS` は分析画面の見出しで使ってよいが、初めて見る公開トップや操作案内では「間隔をあけて復習」と言い換える。`API`・`クライアント`・`bundle`・`dueAt`・`キュー`・`lesson_viewed` など実装の語は画面に出さない。
- 問題ID（`security-xss-01-q1`）は、問題文を出すまでの識別子として現状維持する（後続タスク候補を参照）。

### 文体・記号・数字

- 説明文・空状態・エラーは「です・ます」調。見出し・ボタン・ラベルは体言止めか動詞の終止形（「教材を読む」「復習を始める」）。ボタン末尾に「。」を付けない。
- 呼びかけの「〜しましょう」は画面冒頭の説明 1 か所までにする（現状維持）。
- 区切りは中黒 `·`（U+00B7、前後に半角スペース）を継続する。日本語の並列は「、」または「・」。
- 数字は半角、単位は数字に詰めて書く（`3問`、`18分`、`1日`）。`StatCard` の値と単位の間隔は現状のまま。
- 件数の単位は、問題は「問」、レッスンは「レッスン」、トピックは「トピック」、活動履歴は「件」とする。due 件数も問題数なので「問」にする（読み上げの「件」を含む）。
- 「再読み込み」「取得」「記録」など送り仮名は現状どおり。表記揺れは見つからなかった。
